# Change Log

## 0.6.0 - 2026-07-14

- Add basic highlighting for `backend_cpp.map` files.
- Add semantic highlighting, diagnostics, and Go to Definition support for NDEF field types
  resolved through the sibling `backend_cpp.map`.

## 0.5.0 - 2026-07-04

- Rename the extension and project branding from struct-gen to Silwright.

## 0.4.0 - 2026-07-03

- Highlight the `transient` field modifier.

## 0.3.0 - 2026-07-03

- Add highlighting, folding, indentation, and definition lookup for `trait` declarations.
- Highlight the `with` keyword and optional-field `?` operator.

## 0.2.0

- Add Go to Definition for node, choice, and enum types in the current NDEF file.

## 0.1.0

- Add initial NDEF syntax highlighting, comments, indentation, and folding support.
